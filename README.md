# 8-Bit ALU Using Verilog HDL ⚡

This project focuses on designing and simulating an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL. The ALU performs arithmetic, logical, shift, rotate, and comparison operations based on a 4-bit selection signal.

# Technologies Used

- Verilog HDL
- Xilinx Vivado / ModelSim
- Digital Logic Design
- RTL Simulation and Verification

# How It Works

The ALU accepts two 8-bit inputs and a 4-bit opcode to select the required operation. The result is generated through combinational logic and verified using a self-checking Verilog testbench that compares expected and actual outputs.

# Objective

To understand RTL design, combinational logic implementation, and functional verification while developing a fundamental digital hardware component used in processor architectures.

# Future Improvements

- Optimize hardware area and propagation delay.
- Improve verification using randomized and exhaustive testing.
- Analyze synthesis reports and timing performance.
- Extend the design with status flags and additional operations.
